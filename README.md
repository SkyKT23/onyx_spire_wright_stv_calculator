# Onyx Spire Wright STV Calculator
 This program was developed to determine the name of the local unit of The Dark Empire costuming club from votes of the membership.
 There were six names to choose from, proposed by the membership, which are hard-coded choices in this program. The top three names
 went to the leadership of The Dark Empire for approval. Note: the first winner was rejected by The Dark Empire leadership, leading
 the second winner to be considered and then approved as the name for the new local unit (called a "spire"). Onyx Spire began
 official operations in Colorado and Wyoming in March 2026.

 A unit test is also written for this program, included in this repository. The addition of more unit tests is intended to verify
 the program's compliance with specific Wright STV rules.
